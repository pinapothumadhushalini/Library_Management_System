# Library Management System – Data Analysis

## Project Overview
This project focuses on analyzing library management data using Python. It explores library records, identifies data quality issues, cleans the dataset, and uses visualizations to understand book availability, categories, authors, and borrowing patterns.

## Objectives
- Inspect the library management dataset.
- Identify missing values and duplicate records.
- Clean and prepare the dataset for analysis.
- Perform exploratory data analysis (EDA).
- Create visualizations to understand patterns in library records.
- Interpret the results and present meaningful insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The project uses a library management CSV dataset containing library-related records. The dataset is inspected and cleaned before analysis.

## Data Analysis Steps
1. Load the dataset.
2. Display the first five records and dataset dimensions.
3. Check missing values and duplicate records.
4. Clean the dataset.
5. Perform exploratory data analysis.
6. Create visualizations such as bar charts, pie charts, and histograms where appropriate.
7. Interpret the results and summarize the findings.

## Project Files
- `library_management.py` – Python source code for data analysis.
- `library_management_200.csv` – Dataset used for analysis.
- `Review_3_Presentation.pptx` – Project presentation.

## How to Run
1. Install Python and the required libraries.
2. Keep the Python file and CSV dataset in the same folder.
3. Install the libraries using `pip install pandas matplotlib`.
4. Run `python library_management.py`.
5. Review the dataset inspection results, cleaning results, visualizations, and insights.

## Conclusion
This project demonstrates how Python-based data analysis can be used to clean, explore, visualize, and interpret library management data.
